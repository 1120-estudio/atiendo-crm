titulo: Red de Supabase configurable para nuevas instalaciones en Coolify
---

El Compose de Coolify permite elegir la red externa de Supabase con `SUPABASE_NETWORK`. Una nueva instalación puede usar el servicio Supabase de su propio VPS. Si la variable está vacía o ausente, se conserva la red de la instalación 1120 existente.
